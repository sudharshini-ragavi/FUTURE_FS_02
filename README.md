# Client Lead Management System (Mini CRM)

This project is built as part of Full Stack Web Development Internship (Task 2).

## Features
- Lead capture form
- Admin dashboard
- Lead status update (New, Contacted, Converted)
- Notes and follow-ups

## Tech Stack
Frontend: HTML, CSS, JavaScript  
Backend: PHP  
Database: MySQL  

## Live Demo
Frontend Demo (GitHub Pages)

## Note
GitHub Pages supports only frontend.  
Full backend (PHP + MySQL) runs on a local server (XAMPP).
